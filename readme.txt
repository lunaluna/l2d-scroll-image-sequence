Plays an image sequence on a canvas in sync with page scroll while the section is pinned.

== Description ==

Scroll Image Sequence adds a block that pins its section to the viewport and
draws an image sequence (numbered frames) on a canvas as the visitor scrolls.

== Installation ==

1. Upload the `l2d-scroll-image-sequence` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. This plugin is not listed on WordPress.org. It can be updated from the Plugins screen: WordPress checks GitHub Releases for new versions.
